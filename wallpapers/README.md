# Wallpapers

`deepseek-neural-whale-4k.jpg` — 3840×2160, original procedural artwork for this rice. A whale built from
neural-network nodes in DeepSeek blue, on a dark ocean gradient. No third-party assets, no logos, no text.

- Regenerate it with `python3 generate.py` (requires Pillow).
- The installer copies it to `~/Pictures/wallpaper.jpg` only if that file does not already exist.
- Free to use and modify with this project.
